# Exact product artwork

This directory is generated by `scripts/fetch-exact-artwork.py`.

- The application never downloads product images at runtime.
- Every `.webp` here must correspond to an entry in `assets/exact-artwork/sources.json`.
- Attribution and per-file licensing are written to `ATTRIBUTION.generated.json`.
- Missing model/mode photos fall back to the original AirBattery SVG catalog.
- Do not add manufacturer press images or AI-generated lookalikes.

To refresh the approved set:

```bash
python3 scripts/fetch-exact-artwork.py
python3 scripts/verify-exact-artwork.py
```
