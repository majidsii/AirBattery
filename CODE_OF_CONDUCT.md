# Code of Conduct

AirBattery contributors are expected to keep collaboration respectful, technical, and safe.

## Expected behavior

- Treat people with patience and professional respect.
- Critique code and evidence rather than people.
- Welcome questions and explain platform-specific assumptions.
- Protect private hardware captures, identifiers, credentials, and diagnostic data.
- Correct inaccurate compatibility or test claims promptly.
- Accept maintainer decisions on scope, security, licensing, and release evidence.

## Unacceptable behavior

- Harassment, threats, discriminatory language, or targeted humiliation.
- Publishing another person’s private information or device captures.
- Deliberately misleading test, security, or compatibility claims.
- Introducing malicious code, hidden telemetry, credential theft, or supply-chain abuse.
- Repeated disruption after a maintainer has set a clear boundary.

## Enforcement

Maintainers may edit or remove contributions, comments, issues, or access that violate this policy. Reports should use the private channel described in `SECURITY.md` when privacy or safety is involved. Enforcement decisions should be documented privately, proportionate to the behavior, and focused on protecting the project and its contributors.
